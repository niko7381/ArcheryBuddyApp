# ArcheryBuddyApp
This app is create do help archers get a better perspective on how much they train and their progress.

## Funcionalitys
This app have the following functionalitys:
-   Scoring
-   Physical-Training
-   Training-Log
-   Statistics
-   Specsheet
-   Settings

## Scoring
This functionality is there so the archer have a digitalized scorcart, the scores are saved and used in the statistics functionality.

## Physical-Training
This functionality is there to help the archer register how much physical training the do, this is importent and plays a good roll in an archers training.

## Training-Log
This functionality is there to help the archer register how their training behind the bow went, this can contain information about the weather or what the archer is working on.

## Statistics
This functionality is there to help the archer see if they are making progress and see if their scores are getting any better. 

## Specsheet
This functionality is importen because sometimes you try something as an archer with your equipment and sometimes is goes bad so you need to roll back your changes, this is an overview of the specifications of the archers equipment.

## Settings
This page give the user access to change their password and email adress.
